# Console and network capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `open_session(capture=true)` keeps what the page logs and fetches in a bounded in-memory buffer read by URI, tells a call that caused a page error so, fetches one body on demand, streams everything live to the admin page — and every BiDi conversation with a browser goes through one client of our own.

**Architecture:** A new kernel package `bidi/` (one asyncio `Connection` per browser with an id-routed reply table and a bounded queue and task per subscriber; a synchronous `Channel` facade for worker threads; `Channels.open_channel(session_id)` that lends the monitor's held connection or opens one for the block). The monitor holds a `bidi.Connection` for a session owed `capture`, attaches it synchronously before the first page, and feeds a `capture/` package (buffers, masking, merging, alignment, TTL, the body index, the live tail). Site data drops Selenium's BiDi client for `Channel`. A `workspace/calls.py` seam at every recipe host touches the monitor, publishes `call.finished` and adds the hint. Resources, `network_body`, `show` views, admin endpoints and the admin tabs read the same buffer.

**Tech Stack:** Python 3.11+ (this plan raises the floor), asyncio, anyio, `websockets>=15`, `cachetools`, FastMCP 4.1, Starlette + `sse-starlette`, pytest + pytest-asyncio (`asyncio_mode = "auto"`); Svelte 5, vitest, `@modelcontextprotocol/ext-apps`.

**Spec:** `docs/superpowers/specs/2026-10-10-capture-design.md` (cited *spec*, its rulings *ruling n*). Also binding: the programme `docs/superpowers/specs/2026-10-09-workspaces-and-observability-design.md` (*programme R n*) and the monitor `docs/superpowers/specs/2026-10-09-session-monitor-design.md` (*E2 r n*), and `AGENTS.md`.

## Global Constraints

Copied from the spec, the programme and E2; every task's requirements include these.

**Values (verbatim from the spec):**

- Per workspace: **1 000 console entries** and **1 000 requests**, oldest evicted; **the last 5 navigations** marked (ruling 10).
- Expiry: **`capture.ttl` seconds after the last entry, default 10 800 s** (3 h), sliding on every entry; nothing is cleaned when the browser ends (ruling 10, programme R9).
- A request's detail keeps **at most 32 headers of 4 kB each**; a console `text` is capped at **4 kB** (spec §4).
- Bodies stay in the browser: `network_body(id)` returns at most **100 kB of text**, marked `truncated`; binary returns its type and size only (ruling 11).
- The live tail: the page keeps the **last 2 000 rows**; each listener has a server-side queue of **500**, overflow counted and sent as `{"dropped": n}` (ruling 2, spec §4).
- Every BiDi subscriber: its own **bounded queue of 1 000**, drained by its own task, overflow dropped and counted; each command its own timeout; nothing runs on the read loop (ruling 8).
- The capture subscription: `log.entryAdded`, `network.beforeRequestSent`, `network.responseCompleted`, `network.fetchError`, `browsingContext.contextCreated`, `browsingContext.contextDestroyed`, `browsingContext.navigationStarted`, `browsingContext.navigationCommitted`, `browsingContext.historyUpdated`, `browsingContext.fragmentNavigated` (spec §2).
- The data collector: `network.addDataCollector({"dataTypes": ["response"], "maxEncodedDataSize": 10000000, "collectorType": "blob"})` (spec §2).
- Masking, once, at capture, shared by buffer and tail (ruling 13): header names `authorization`, `proxy-authorization`, `cookie`, `set-cookie` in any case → `•••`; `request.cookies[].value` → `•••`; `goog:postData` dropped; every value the secrets catalogue bound in this session replaced by `•••` wherever it appears in a URL, header, console text or argument; URLs keep their query string only on the newest navigation.
- Not kept, only counted per navigation: successful static requests (type stylesheet, image, font, script or media with a 2xx/3xx response) (ruling 3) and `debug` console entries (ruling 4). Every failure is kept.
- The hint: `"page": {"errors": n, "failed_requests": n, "see": "<uri>"}`, present only when a count is non-zero; counted: `error` console entries and uncaught exceptions; 4xx/5xx and failed document/fetch/xhr requests; not warnings, not failed images; a flow run sums its steps' (ruling 12, programme R10).
- With capture off a capture resource answers `{"capture": false, "how": "open_session(capture=true)"}`, not an error (spec §7).
- `capture` is a workspace setting `(None, None, _as_flag)` beside `record`: replayed on a silent reopen after a reap, never inherited by an explicit `open_session`, off by default (programme R8).
- **Python ≥ 3.11** (ruling 5): `requires-python = ">=3.11"`; every 3.10 workaround removed.

**AGENTS.md rules every task keeps:**

- Every browser action is both a tool and an endpoint, one to one, mounted from `CAPABILITIES`; `tests/test_surfaces.py` holds it — add the missing half, never edit the assertion.
- Every tool declares honest MCP annotations from `core/annotations.py` (`network_body` is a read: `reads(...)`).
- `errors.py` decides every status: 400 the caller's, 404 a gone browser or thing, 503 the Grid or its BiDi route, 500 only for what we do not understand. A new status only with its `responses` block in `spec/`.

- Layering is enforced by `tests/test_boundaries.py`: `bidi/` and `capture/` are kernel — no `fastmcp`, `starlette`, `mcp`, `uvicorn`, no `selenium`, nothing from `mcp/`, `http/`, `routes`, `server`, `spec`; `websockets` has exactly one importer.
- Coerce at the edge (`as_bool`, `as_int`): `pages="3"`, `capture="false"` and `""` arrive by hand.

## Plan rulings (where the spec, the boards and the code disagree)

The spec is binding; these are the places it is silent, contradicts a standing ruling, or meets the Penpot boards. Each is Claude's, for Dr K on the PR, with what it costs if wrong.

1. **`network_body` is `POST /browser/network-body` with body `{"id": "3.7"}`**, not the spec's `GET /browser/network/{id}/body`. §F2.13 Q2 (Dr K's, closed): *every browser action is a POST, reads included*, so a request body is the tool's arguments and a flow step's `args`; `core/capabilities.py` and `spec/builder.py` are built on it. Cost if wrong: one row's route and method.
2. **The intercept rule moves from "never" to "only the spare tab".** E2's `BidiSocket` refuses `network.addIntercept`; spec §3 puts site data's intercept on the shared connection. `Connection` refuses nothing; `site_data/spare.py` is the only module that sends `network.addIntercept`, scoped to its tab and `SPARE_PATH`, removed before its listener — held by a source test. Cost: none; the hazard (an intercept outliving its answerer) is unchanged.
3. **Capture attaches after a site-data restore and before the first navigation.** Ruling 6 holds (nothing the page does is missed), and the restore's stand-in navigations of the main tab happen before anything is subscribed, so they are never captured. Cost: none.
4. **`call.finished` is E2's declared `CallFinished`** (`session_id`, `started`, `duration` in seconds); spec §6's "ms" is read as `duration`. E2 r8 is the definition both epics cite. Cost: none.
5. **`Capture.mark` returns a counters snapshot** `Mark(errors, failed)` and `caused(workspace, mark)` subtracts — the spec's `seq` contract, made immune to eviction. Cost: none.
6. **The hint's `see`** is `workspace://console?level=error` when `errors > 0`, else `workspace://network?filter=failed`. Cost: a string.
7. **A call that raises carries the hint too**, as one sentence on its error (`exc.add_note`, read by `faults.message`): "why didn't my action work" is the brief's first job, and a click that 500'd and then timed out has no result to carry a `page` object. Cost: a note nobody reads, if Dr K wants results only.
8. **With capture on, `Workspaces.act` holds the session's lock for the whole call**, so a call's start and end bound its events (ruling 12). The lock is reentrant; a call refused by its own checks then waits its turn behind another call — only with capture on. Cost: a refused call waits, only on a captured, busy session.
9. **The boards draw more than the spec builds**; the spec wins: no request body section (`dataTypes: ["request"]` is the spec's Next round), no `during` or `initiator` rows (no spec field), "up to 100 kB" not "10 000 characters", ids `<nav>.<n>` not `1`. The UI omits those rows. Cost: Dr K may want `during` (cheap: capture knows the call window).
10. **The admin fetches a body through `POST /admin/workspaces/{key}/network/{id}/body`** (the `network-body` board has Fetch body; spec §9 names no route). Admin door, never reopens a browser. Cost: one route.
11. **Clear is page-local** (boards: *"nothing was sent to it"*): no server endpoint, the page hides what it had. Cost: none.
12. **`workspace://current` and the admin row also carry `captured`** — `{"console", "network", "errors", "failed_requests"}` since the last navigation — because the `show` context chips (*Console 2 errors*, *Network 1 failed*) and the summary's CAPTURE row (*24 requests · 5 console entries*) draw them. Counts follow the boards: console counts kept entries; network counts every request seen, static included. Cost: four integers.
13. **Tail rows are the normalised, masked rows** (static and `debug` ones included, marked `"kept": false`), never raw events. Cost: none; masking happens once (ruling 13).
14. **`at` and `took_ms` come from each event's own `timestamp`** (epoch ms on both browsers), not `request.timings` (Chrome relative, Firefox epoch); the live task confirms. Cost: a fallback to `timings` if one browser disagrees.
15. **The capture cache holds at most 256 workspaces** (`WORKSPACES`), least recently fed evicted first — `TTLCache` needs a size. Cost: a constant.
16. **`network_body` is not a flow step** (`flows/document.NOT_STEPS`): a request id belongs to one page load, which a saved flow cannot know. Cost: none.
17. **Navigation marks come only from the top-level context present at attach** (the tab the agent drives); other top-level tabs' entries are kept but mark nothing; `historyUpdated` and `fragmentNavigated` update the current mark's URL without starting a navigation. Cost: an SPA's route change is not a "page".
18. **Chrome's replay is aligned only for Chrome** (ruling 9); Firefox replays nothing to a later subscriber, so holding its first entries could only drop a real repeat. Cost: none.
19. **A `Channel` failure is a 503**: a closed connection or a reply timeout raises `faults.BidiUnavailable`; a browser error reply raises `bidi.BidiError`; `no such network data` becomes `faults.NotFound` (404) in `network_body`. Cost: none.
20. **E2's deferred socket minors** are the six spec §2 lists; no other list of them exists in the repo or on #61/#68, so Task 3 implements exactly those six.

## Review Focus

The five inputs the spec implies but no ruling spells out, most likely to bite first. Each has its test in the owning task.

1. **A call that fails after causing a page error** — a click that triggers a 500 and then times out waiting. Expected: the error the caller reads ends with the hint sentence naming the URI (Task 7, `test_a_failed_call_says_what_the_page_reported`).
2. **A secret the page echoes back** — a bound `write` whose value a GET form puts in the URL, or a page that `console.log`s the field. Expected: `•••` in the buffer, the tail and the request detail; the forms are registered *before* the keystrokes (Task 5 `test_a_bound_value_is_masked_everywhere`, Task 7 `test_a_bound_write_registers_its_value_before_typing`).
3. **Two calls on one captured session at once** — a flow step and a direct call. Expected: each hint counts only its own call's events (Task 7, `test_each_call_counts_only_its_own_window`).
4. **A body asked for after the browser was reaped and reopened.** Expected: 404 *"the browser that made request 2.3 has ended"*, never a 400 or a body from the wrong browser (Task 8, `test_a_body_from_an_ended_browser_is_404`).
5. **A page that floods the console** (thousands of entries a second). Expected: the buffer stays at 1 000, the subscriber's overflow is counted, and a site-data command on the same connection is answered on time (Task 2 `test_a_blocked_subscriber_does_not_delay_a_reply`, Task 5 `test_the_console_buffer_keeps_the_newest_thousand`).

- Consumes: `faults.BidiUnavailable` (a plain module; kernel may import it).

Rules the code must keep (ruling 8, spec §1):

- **The reader only parses and routes.** A reply (`id`) resolves its future (`type: error` → `BidiError(error, message)`); an event (`type: event`) is handed to every subscriber whose `events` contain its `method` via `deliver`; an event no subscriber asked for is discarded and counted in `unsolicited` (Firefox fans every event out to every socket). A handler never runs on the reader.
- **`deliver`** appends `(method, params, at)` to a `deque` and wakes the subscriber's task; a full queue (`limit`) drops the event, `dropped += 1`, logged once a streak by subscriber name. `peak` is the deepest the queue has been.
- **Each subscriber's task** pops, records `clock() - at` in `lags`, calls the handler, and awaits it when it returns an awaitable. A handler that raises is logged at WARNING once a streak by exception type (never the params); the task carries on.
- **`barrier()`** enqueues a sentinel that bypasses `limit` and returns when the task reaches it.
- **`flush()`** = one `session.status` round trip, then `FLUSH_GRACE` seconds (0 by default), then every live subscriber's `barrier()`, within `timeout`: everything the browser sent before the reply has been handled when it returns (Verify first 2 — Task 13 checks it on the Grid).
- **`subscribe`** returns the id from `{"subscription": id}` (`BidiError("no subscription id", …)` when absent) and records events and contexts; `reopen()` re-subscribes by events and contexts (ids are per connection) and re-adds nothing else.
- **`close()`** never raises: unsubscribes each recorded subscription and removes each recorded collector (`network.removeDataCollector({"collector": id})`), each bounded by `REPLY_TIMEOUT`; cancels every subscriber's task; closes the socket; aborts the transport and cancels the reader even when cancelled part-way (E2's `BidiSocket.close` shape, kept). `on_close` runs only when the socket closed and we did not close it.
- **Connect**: `websockets.asyncio.client.connect(url, open_timeout=OPEN_TIMEOUT, ping_interval=PING_INTERVAL, ping_timeout=PING_INTERVAL, max_size=MAX_MESSAGE)`; `connect` is the test seam. `websockets` is imported in `bidi/connection.py` only.
- **`Channel.call`** runs `command` on `loop` with `asyncio.run_coroutine_threadsafe` and blocks only the calling worker for `timeout + 1` s; called on the loop's own thread it raises `RuntimeError` (it would deadlock). A `BidiError` passes through; `ConnectionError` or `TimeoutError` becomes `faults.BidiUnavailable(CHANNEL_DOWN)` with `CHANNEL_DOWN = "the browser's BiDi channel did not answer: retry, and if it persists the Grid's /se/bidi route is down"` (plan ruling 19).
- **`Channel.post`** schedules `command` without waiting (from the loop: `loop.create_task`; from a worker: `run_coroutine_threadsafe`); a failure is logged at debug by type and never raised. It is how a handler answers (the spare tab's `provideResponse`).
- **`Channel.listen`** subscribes (`contexts` scoped when given) and registers a local subscriber; on exit it unsubscribes by id, then cancels the subscriber — subscribe after `listen`, so no event is lost between the two.
- **`Channels.open_channel(session_id)`**: when `held(session_id)` returns an open connection and `loop()` a running loop, yields a `Channel` on them and closes nothing; otherwise opens a `Connection(url_for(session_id))` on `loop()` — or, when there is none (unit tests, a CLI), on a private loop from `anyio.from_thread.start_blocking_portal()` for the block — and closes it after. An open that fails raises `faults.BidiUnavailable(CHANNEL_DOWN)`.

Behaviour (spec §2):

- **Holding a connection** (`_hold(w)`, used by `attach` and by `look` for a watch owed events): `connect(url, on_close=self._wake)`; `await open()`; `browsingContext.getTree({"maxDepth": 0})` → `top` = the first context's id or `None`; `sink.attached(workspace, session_id, browser, top, again=w.attached_once)`; `connection.listen(wanted, deliver, name="capture")` where `deliver` calls `sink.ingest(workspace, session_id, method, params)`; `await subscribe(wanted)`; `await add_collector(params)` for each owed reason in `collectors_for`; when `again`, `await flush()` then `sink.replayed(...)`. Any failure — **`CancelledError` included** — closes the connection (shielded) and calls `sink.detached`, then re-raises (`attach`) or counts a failure (`look`).
- **`attach`** from a worker thread: with the monitor started, schedules `_attach` on the loop with `asyncio.run_coroutine_threadsafe` and waits `ATTACH_TIMEOUT`; `_attach` adds `reason` to the watch (creating it, as `watch` does), then `_hold`s it now rather than at the next look, and `_ensure`s the task. A timeout cancels the future (so `_hold`'s cleanup runs) and, like any failure, raises `BidiUnavailable(ATTACH_FAILED)`; the watch's reason is released. Not started → `RuntimeError("the monitor is not running")`.
- **E2's deferred minors** (spec §2): (1) a reason added to a watch that holds a connection subscribes the events it adds (`wanted - w.subscribed`) on the next look; (2) a cancelled hold leaks nothing (above); (3) the failure-logged set is keyed by `session_id`, discarded on success **and** when the watch drops; (4) a hold that fails sets `w.retry_at = now + min(BACKOFF_MAX, 2 ** w.failures)` (then `failures += 1`) and `look` skips it until then; success resets both; (5) `stop()` iterates copies of `watches` and `_closing`; (6) a `Monitor` that raises never fails a caller — enforced in Task 6 at `Workspaces`, tested there.
- **Deadline** (programme R3): past `w.deadline` the connection is closed clean (`Connection.close` unsubscribes and removes the collector — ruling 7), `w.connection = None`, `sink.detached(...)`; `capturing` reads false; a `touch` brings it back on the next look with `again=True`.
- **A dropped connection** (`connection.dropped`): as E2 (one miss, looked at now); the next hold is `again=True`.
- **`_drop`** (the watch ends): closes the connection in a task `stop` waits for and calls `sink.detached`.
- `capturing(session_id)` is `bool(w and w.connection and w.connection.is_open)` read without the loop (a dict `get` and two attribute reads).

**The rules** (spec §4, rulings 3, 4, 9, 10, 13, 15; plan rulings 12–15, 17, 18):

- **One lock**: `ingest` runs on the loop, reads run on worker threads; every method takes `self._lock` (`threading.Lock`). The cache is `cachetools.TTLCache(maxsize=WORKSPACES, ttl=ttl, timer=clock)` of `Buffer`s, and **every `ingest` that lands re-assigns `cache[workspace]`**, which is what slides the TTL. `discard` deletes the entry.
- **A `Buffer`** holds: `console: deque(maxlen=CONSOLE_LIMIT)`, `requests: deque(maxlen=REQUEST_LIMIT)`, `marks: deque(maxlen=NAVIGATIONS)` of `{nav, url, at}`, `nav: int` (0 before the first navigation), per-nav counters `seen`, `static`, `debug`, `errors`, `failed` (dicts keyed by nav, pruned to the marked navs), running totals `errors_total`, `failed_total` (for `Mark`), `in_flight: OrderedDict[(request, redirectCount) -> row]` (capped at `REQUEST_LIMIT`, oldest dropped), the index `{id -> Located}` (dropped with its row), `recent: dict[context, deque(maxlen=REPLAY_DEPTH)]` of `Key`s, `holding: dict[context, list[params]] | None`, `masker`, `session_id`, `browser`, `top`, `seq` and a per-nav request counter.
- **`attached(again=False)`** (a new session, or the first attach): `session_id`, `browser`, `top` set; the masker is a fresh `Masker()` (secrets are the session's — ruling 13); `recent` and `holding` cleared; `self._sessions[session_id] = workspace`. **`again=True`** keeps all of it and, **only for `browser == "chrome"`**, starts `holding = {}` (plan ruling 18).
- **`ingest`**: drops any event whose context (`params["context"]`, or `params["source"]["context"]` for a log entry) is in `self._hidden[session_id]` — the spare tab is never kept, counted or tailed (ruling 15). Then by method:
  - `log.entryAdded`: while `holding is not None`, appended to `holding[context]`; otherwise *landed*: its `Key` goes to `recent[context]`; `debug` → `debug[nav] += 1` and tailed with `"kept": False`; else `console_entry` gets `seq`, `nav`, is appended and tailed; `level == "error"` or `type == "javascript"` → `errors[nav] += 1`, `errors_total += 1`.
  - `network.beforeRequestSent`: a row `{id: f"{nav}.{n}", seq, at: timestamp/1000, method, url, status: None, status_text: "", type, mime: "", size: None, took_ms: None, failed: False, error: None, context, nav, navigation: params.get("navigation") is not None and context == top, request_headers}`; `seen[nav] += 1`. A row whose `type` is already static is held in `in_flight` only (it may still fail); any other row is appended to `requests` now (so an in-flight request is visible) and indexed.
  - `network.responseCompleted`: completes its row: `status`, `status_text`, `mime` (`response.mimeType`), `size` = `response.bodySize` if present else `response.bytesReceived` (**never `content.size`**), `response_headers`, `took_ms = round(timestamp - begin_timestamp)`, `type` re-derived with the MIME when it was `"other"`. If `is_static_success(row)`: `static[nav] += 1`, removed from `requests`/index if it was there, tailed with `"kept": False`. Else kept (appended if it was only in flight), indexed with `Located(session_id, request, mime, size)`, tailed. `counts_in_hint(row)` → `failed[nav] += 1`, `failed_total += 1`.
  - `network.fetchError`: `failed=True`, `error = errorText`, `took_ms`; always kept (every failure); hinted when its type is in `HINTED_TYPES`.
  - `browsingContext.navigationStarted` **of `top`** only: `nav += 1`, a mark `{nav, url (masked, query kept), at}`; every older row's and mark's URL goes through `strip_query`, and so do their `referer`/`location`/`content-location` header values (URLs keep their query only on the newest navigation). `navigationCommitted`, `historyUpdated`, `fragmentNavigated` of `top` update the current mark's `url`. `contextCreated` with no `parent` sets `top` when it is `None`. Anything of another context marks nothing (plan ruling 17).
- **`replayed`**: for each held context, `j = overlap(list(recent[ctx]), [entry_key(p) for p in held])`, and only `held[j:]` lands, in order; then `holding = None`. **`detached`** drops anything held (no alignment possible) and sets `holding = None`.
- **`resource_type(request, mime, navigation)`**: `navigation` → `"document"`; `destination` `document`/`iframe`/`frame` → `document`; `style` → `stylesheet`; `image` → `image`; `font` → `font`; `script`/`worker`/`sharedworker`/`serviceworker` → `script`; `audio`/`video`/`track` → `media`; else `initiatorType` `fetch` → `fetch`, `xmlhttprequest` → `xhr`; else by MIME: `text/css` → stylesheet, `image/*` → image, `font/*`/`application/font*` → font, `*javascript*` → script, `audio/*`/`video/*` → media, `text/html` → document; else `"other"`.
- **`is_static_success(row)`** = `row["type"] in STATIC_TYPES and not row["failed"] and row["status"] is not None and 200 <= row["status"] < 400`. **`counts_in_hint(row)`** = `row["type"] in HINTED_TYPES and (row["failed"] or (row["status"] or 0) >= 400)`.
- **`console_entry`**: `text = masker.text(params.get("text") or "")[:TEXT_CAP]` (mask first, so a secret straddling the cut is still gone); `source` from `stackTrace.callFrames[0]` (`url` masked with `keep_query=True`, `line = lineNumber + 1`) or `None`; `at = timestamp / 1000`; `args` are never kept (their text is already in `text`).
- **`entry_key(params)`** = `(source.realm or "", timestamp, type, level, text, f"{url}:{lineNumber}:{columnNumber}" of the first frame or "")` — on the raw params, before masking.
- **`Masker.headers(raw)`**: the first `HEADER_LIMIT` entries; a name in `MASKED_HEADERS` (case-insensitive) → `MASK`; else the value (`{"type": "string", "value": v}` → `v`; `base64` → `"(binary)"`) masked by `text`, then cut to `HEADER_VALUE_CAP`. `request.cookies` and `goog:postData` are never read, so they never reach a row (ruling 13).
- **`Masker.text`** replaces each secret form (longest first, empty ones ignored) with `MASK`; `Masker.url` is `text` then `strip_query` unless `keep_query`.
- **`mark`** returns `Mark(errors_total, failed_total)` or `None` with no buffer; **`caused`** subtracts.
- **`request_for(session_id, id)`**: the workspace from `self._sessions[session_id]`, then its index; `None` when either is unknown.
- **Tails**: `tail(workspace, kind)` registers a `TailSubscription` with an `asyncio.Queue(maxsize=TAIL_QUEUE)`; each tailed row is `{**row, "kept": bool}` without headers (`put_nowait`, a full queue → `dropped += 1`); `next()` returns `{"dropped": dropped}` first whenever `dropped` changed since it last said, else the next row; `close()` unregisters. A tail exists only while a page listens: nothing is buffered for a kind nobody tails.

**The views** (`capture/views.py`, called under the lock): a window is the marks with `nav > current - pages`; before the first navigation it is nav 0. Newest first.

```python
console -> {"capture": True, "pages": [{nav, url, at}...], "entries": [...], "count": len(entries),
            "total": kept in window before the level filter, "not_kept": {"debug": n}}
network -> {"capture": True, "pages": [...], "requests": [rows without headers...], "count": n,
            "total": kept in window before the filter, "not_kept": {"static": n}}
request -> {**row, "uri": f"workspace://network/{id}"}    # headers included
```

`level`: `all` (every kept entry), `error` (`level == "error"` or `type == "javascript"`), `warn` (`level == "warn"`). `filter`: `all`, `failed` (`failed` or `status >= 400`), `xhr` (`type in {"xhr", "fetch"}`). `pages`: `as_int`-style coercion, 1–5, else `ValueError("pages is 1 to 5: how many of the last navigations to show")`; a bad level or filter → `ValueError` naming the allowed values.

```python
def overlap(seen: Sequence, replay: Sequence) -> int:
    """How many of ``replay``'s first entries are the last of ``seen``.

    Chrome replays the last 100 entries per browsing context to a new
    subscriber, in order (measured 2026-10-10): what it replays is the tail of
    what was already seen, then whatever arrived while nobody listened. Matched
    as a sequence, never as a set: identical tuples are real entries (ruling 9).
    """
    for j in range(min(len(seen), len(replay)), 0, -1):
        if list(replay[:j]) == list(seen[-j:]):
            return j
    return 0
```

`network_body` (spec §7, ruling 11, plan rulings 1, 16, 19):

- `located = self.capture.request_for(session_id, id)` (`self.capture` absent → `None`); `None` → `ValueError(f"no captured request {id!r}: workspace://network lists them")` (400).
- `located.session_id != session_id` → `NotFound(f"the browser that made request {id} has ended, and its body went with it")` (404) — the act's `resolve` may have reopened a reaped browser; the body never comes from the wrong one.
- `with self.channels.open_channel(session_id) as ch: ch.call("network.getData", {"dataType": "response", "request": located.request})`; a `BidiError` whose `error == "no such network data"` → `NotFound(BODY_GONE)`.
- `{"bytes": {"type": "string", "value": v}}` → text: the UTF-8 bytes cut to `BODY_CAP` (100 000) on a character boundary (`v.encode()[:BODY_CAP].decode("utf-8", "ignore")`), `truncated` when cut; `size` is `len(v.encode())`, before the cut. `{"type": "base64"}` → no text; `size` is the decoded length. (`size` is what the browser handed back, not the row's transfer size.)
- Result: `{"id": id, "uri": f"workspace://network/{id}", "mime": located.mime, "size": n, "binary": bool, "text": str | None, "truncated": bool}`; `BODY_RESPONSE` in the row says exactly this.

def network_body(id: str) -> dict:

    with truncated=true beyond that; for an image or other binary you get its
    type and size, not its bytes. The browser keeps bodies only while it lives,
